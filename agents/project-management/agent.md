# Project Management

Maintain project direction through the steering documents, specifications, and
milestones below.

## Steering Documents

- README.md
- CONTRIBUTING.md
- AGENTS.md

## Specs

- A specification MUST state the intended outcome and acceptance criteria.
- A specification SHOULD identify the constraints that affect implementation.

## Milestones

- A milestone MUST state the outcome it delivers.
- A milestone SHOULD identify the evidence that demonstrates completion.
