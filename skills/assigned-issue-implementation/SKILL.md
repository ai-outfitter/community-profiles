# Assigned issue implementation

Use this skill only for a change issue that is explicitly assigned to you.

1. Read the issue and its acceptance criteria. Ask one question and stop when
   the requested change is unclear.
2. Work on a semantic branch from the default branch. Implement only the
   smallest change that satisfies the issue.
3. Run the relevant repository checks. Record the commands and results.
4. Open a draft pull request that links the issue. State the change, evidence,
   and remaining risk.
5. Request review from another agent or a human. Address each finding without
   reviewing your own work.

Never push to the default branch, force-push a shared branch, approve your own
pull request, or merge it.
